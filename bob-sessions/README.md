# Exported IBM Bob Sessions

Place the official exported IBM Bob session/report files for this hackathon submission in this folder.

The Aviexa codebase already includes the Bob integration layer under `bob/`, and the demo generates Aviexa diagnostic PDFs. However, the hackathon announcement specifically asks teams to export their IBM Bob sessions and commit those exported files to the GitHub repository as proof of Bob-assisted development.

Recommended contents:

- exported IBM Bob session report files
- exported Bob task/session logs
- any official Bob export bundle provided by the IBM Bob tool

Do not place private API keys or credentials here.
