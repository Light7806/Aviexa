# Exported IBM Bob Sessions

This folder contains exported IBM Bob task/session markdown files for the Aviexa hackathon submission.

The hackathon guide asks teams to export Bob sessions and commit them to a `bob_sessions` folder in the GitHub repository. The task exports in this folder document the Bob-assisted project work used while building Aviexa.

Expected contents:

- `bob_task_1.md`
- `bob_task_2.md`
- `bob_task_3.md`
- `bob_task_4.md`
- `bob_task_5.md`
- `bob_task_6.md`
- optional task-header screenshots showing context length, task id, tokens, API cost, and size

No API keys or credentials should be committed here.
